## Evidence levels and claim rules

- **Current API observation:** a file, branch, commit or document was read or written through its connected service in this batch. This supports document provenance, not software behavior.
- **Historical reported completion:** an existing dated report records a result. Preserve its date, scope and caveats; never relabel it as a new test.
- **Documented, not independently verified:** a capability or wider-network statement appears in the source documentation but was not exercised here.
- **Evidence unavailable:** a referenced receipt is missing from the reviewed source inventory. Leave the state explicit.
- **Editorial synthesis:** newly written copy grounded in cited facts, not a verbatim recovery of an entire website page.

Synthetic examples are not production measurements, customer endorsements, guarantees, SLAs or certification. A protocol terminal is not semantic correctness; valid JSON is not authorization; a timeout or unreadable response is not proof that a mutation failed; CORS is not authentication, authorization or consent; modeled idempotency is not exactly-once execution.
